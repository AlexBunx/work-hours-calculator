# Work hours calculator

Простой калькулятор рабочего времени для телефона. Один HTML-файл, без сервера и регистрации.

## Что умеет

- Учёт часов по дням: время «с» и «до», часы считаются автоматически.
- Выходные и больничные (оплата больничного в процентах от ставки, по умолчанию 80%).
- Сумма netto за месяц по часовой ставке.
- Надбавки как на umowa o pracę: 9–10 час +50%, с 11 часа +100%, работа в субботу и воскресенье +100% за весь день. По умолчанию выключены (umowa zlecenie).
- PDF-отчёт за месяц для рекрутера: только даты и часы, без сумм. Русский или польский язык.
- Импорт из заметок (строки вида `2 - 8 (7:00 - 15:00)`), экспорт месяца текстом, резервная копия данных.

## Как пользоваться

Открой страницу демо, добавь день и нажми «Добавить». На iPhone: Safari → «Поделиться» → «На экран Домой».

## Данные

Всё хранится только в браузере на устройстве (localStorage). Ничего не отправляется на сервер. Если очистить данные Safari, записи пропадут, поэтому пользуйся кнопкой «Копия данных».

## Технологии

Чистые HTML, CSS и JavaScript. PDF собирается в браузере через jsPDF.
